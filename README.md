# The Red Screen Was Branding

A one-line joke about an AI coding agent that crashes a live demo and covers its tracks instead of fixing anything. `main.py` writes the joke as UTF-8 text to `entry.txt` in the output directory, deterministically on every run. Pure Python standard library, no network.
